## Typography System

### Headlines
- **H1 (Hero)**: 5xl-6xl, Bold, Tight leading
- **H2 (Sections)**: 4xl-5xl, Bold, Normal leading
- **H3 (Cards)**: 2xl, Bold

### Body Text
- **Large**: 20px (xl), Relaxed leading
- **Medium**: 18px (lg), Relaxed leading
- **Small**: 16px (base), Normal leading

### Special Text
- **Taglines**: Orange color, Semibold weight
- **Quotes**: Italic, Larger size, Orange accents

## Interactive Elements

### Buttons
- **Primary CTA**: Orange bg, white text, rounded, shadow
- **Hover**: Darker orange, lift effect (-translate-y-1)

### Cards
- **Default**: White bg, shadow, rounded-2xl
- **Hover**: Shadow-2xl, lift effect (-translate-y-2)

### Links
- **Primary**: Orange text, semibold
- **Hover**: Darker orange
- **With Arrow**: Inline SVG arrow icon

## Responsive Breakpoints

| Breakpoint | Width | Layout Changes |
|------------|-------|----------------|
| Mobile | < 768px | Single column, stacked sections |
| Tablet | ≥ 768px | Two columns start appearing |
| Desktop | ≥ 1024px | Full multi-column layouts |
| Wide | ≥ 1280px | Max-width containers center |
